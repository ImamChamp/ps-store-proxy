# PS Store (Турция) через прокси

Скрипт перебирает бесплатные турецкие прокси, находит рабочий и открывает через него Chromium с PlayStation Store для региона Турции (`store.playstation.com/tr-tr/`).

## Как это работает

1. Если в профиле браузера нет входа в PSN, скрипт сначала открывает браузер **без прокси**. Войдите в аккаунт и закройте окно.
2. Скрипт собирает кандидатов в прокси из нескольких открытых источников и отбрасывает дубликаты.
3. Каждый прокси проверяется параллельно: он должен отвечать, определяться как турецкий (`country.is`) и отдавать страницу PS Store.
4. Первый прокси, который прошёл проверку, открывается в браузере с сохранённым профилем, так что вход в PSN уже есть.

Вход в аккаунт выполняется без прокси, потому что защита Sony блокирует вход через прокси и через браузер под управлением автоматизации.

## Установка

Нужен Python 3.10 или новее.

```bash
pip install requests[socks] playwright
playwright install chromium
```

## Запуск

```bash
python ps_store_tr_proxy.py
```

Примеры с параметрами:

```bash
# свой список прокси (ip:port или схема://ip:port, по одному на строку)
python ps_store_tr_proxy.py --file my_proxies.txt

# больше потоков и больший таймаут проверки
python ps_store_tr_proxy.py --workers 150 --timeout 8

# только турецкие списки, без больших общих
python ps_store_tr_proxy.py --no-big

# другая папка профиля браузера
python ps_store_tr_proxy.py --profile D:/ps_profile

# только войти в PSN (без прокси) и выйти
python ps_store_tr_proxy.py --login
```

### Все параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| `--file` | файл со своими прокси | — (берутся публичные списки) |
| `--workers` | число потоков проверки | 100 |
| `--timeout` | таймаут проверки одного прокси, сек | 8 |
| `--url` | адрес, который открывается в браузере | `https://store.playstation.com/tr-tr/` |
| `--profile` | папка профиля браузера | `browser_profile` рядом со скриптом |
| `--login` | только войти в PSN без прокси и выйти | — |
| `--login-url` | страница, которая открывается для входа | встроенная |
| `--no-login` | не предлагать вход, даже если его нет | — |
| `--no-big` | не загружать большие общие списки прокси | — |

## Важно

- **Папка `browser_profile` содержит вашу сессию PSN.** Не передавайте её никому и не публикуйте. В `.gitignore` она уже исключена.
- **Бесплатные прокси — это чужие серверы.** Их владельцы неизвестны, и трафик через них может читаться. Не вводите через такой прокси пароли и платёжные данные. Вход в аккаунт при этом выполняется без прокси.
- **Смена региона может нарушать условия использования PlayStation Network.** Аккаунт могут ограничить. Вы используете скрипт на свой риск.
- **Скрипт может перестать работать.** Источники прокси меняют форматы и закрываются, а защита Sony обновляется. Если прокси не находятся, попробуйте позже или передайте свой список через `--file`.
- Если профиль уже открыт в другом окне Chromium, скрипт завершится с кодом 3. Закройте то окно и запустите скрипт снова.

## Коды возврата

| Код | Значение |
|---|---|
| 0 | страница открыта, либо выполнен `--login` |
| 1 | список прокси пуст |
| 2 | рабочих турецких прокси не найдено |
| 3 | профиль браузера занят другим окном |
